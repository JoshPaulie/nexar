    Champions

    nexar.champions is a static champion ID-to-name map snapshotted from Data Dragon, so champion ids can resolve to names offline. scripts/regen_champion_names.py refreshes the snapshot on a patch bump. Until it runs, an id newer than the snapshot (or a game-mode id) resolves to None instead of raising.

    Static champion ID-to-name map, snapshotted from Riot's Data Dragon.

    Data Dragon patch 16.23.1: the map is generated once and checked in, so champion ids resolve offline with no runtime network dependency. Refresh it on a patch bump with uv run python scripts/regen_champion_names.py.

    Source: https://ddragon.leagueoflegends.com/cdn/16.23.1/data/en_US/champion.json

    champion_name(champion_id)

    Return the champion's display name for a Data Dragon id, or None.

    None means the id is absent from the pinned snapshot: a champion released after it, or a game-mode id Data Dragon does not list. The raw id stays on the model, and an unknown id is forward drift, not an error; refresh the snapshot with scripts/regen_champion_names.py.
